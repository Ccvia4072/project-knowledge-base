## 🛠️ How to Use It (First 5 Minutes)

### Step 1: Start a New Project File
Open the app and click **"New Project"**. Give it a simple name like "MyWebsite" or "ShoppingApp." This creates a dedicated memory folder for that project.

### Step 2: Connect Your AI Assistant
In the app settings, copy the "memory path" (it looks like `C:\ProjectMemory\MyWebsite`). When using ChatGPT or CodeBuddy, paste this path into your system prompt. Your AI will now know where to save and read project memories.

### Step 3: Begin Working Normally
Just code and chat with your AI as usual. Every few minutes, the software quietly saves important context. You'll see a small notification when a save happens.

### Step 4: Recover After a Break
Next time you open a fresh AI conversation, simply tell your assistant: *"Read the project memory from [path]."* Instantly, it'll recall your goals, file structure, and recent progress.
