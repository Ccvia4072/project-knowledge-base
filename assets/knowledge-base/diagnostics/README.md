# Diagnostic evidence

Create a dated, task-specific directory for each meaningful investigation or experiment. Preserve raw evidence and failed attempts.

Recommended contents:

- purpose and hypothesis;
- environment/configuration manifest;
- exact commands or scripts;
- timestamps, versions, and hashes;
- raw stdout/stderr, logs, captures, plots, or snapshots;
- expected versus actual result;
- first failure point and failure classification;
- conclusion and what the run does not prove;
- cleanup/rollback status;
- deterministic evidence-tree digest when exact provenance matters.

Do not use this directory as the always-read memory layer. Summarize durable conclusions in the appropriate entry file and link here.
